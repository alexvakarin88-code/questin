# Генератор квестов «Тропинка» — прототип

## Страницы
- `generator.html` — клиентская версия анкеты и создания демонстрационного квеста.
- `studio.html` — переход во внутреннюю студию (`generator.html?mode=studio`).
- Оба интерфейса используют общий генератор, расположенный в `generator.html`.

## Что уже работает
- Настройки возраста, темы, места, числа участников, времени, сложности и реквизита.
- Создание структурированного сценария по встроенным шаблонам без внешнего API.
- Легенда, задания, ответы, подсказки, места размещения, финал и правила безопасности.
- Печать / сохранение через диалог браузера в PDF, копирование, TXT и JSON.
- Во внутренней студии — ручная редактура, базовая проверка комплектности и локальное сохранение черновиков.

## Чего пока нет
- Генерации языковой моделью: серверный API ещё не подключён.
- Общей базы заказов и черновиков, входа администратора, оплаты и защищённой выдачи файлов.
- Реальной отправки клиентского заказа.

## Безопасность
- Не размещать API-ключи в HTML или JavaScript.
- Внутренняя студия не защищена паролем и не является закрытым кабинетом.
- localStorage хранит черновики только в текущем браузере и не синхронизирует их между устройствами.
- Не вводить реальные персональные данные детей до подключения серверного хранения, авторизации и проверки политики конфиденциальности.
